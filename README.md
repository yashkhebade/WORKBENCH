## ✨ Features

- 🏗️ **Hardware-Centric Workflows:** Kanban boards tailored for hardware development with custom steps like *Ideation, Design (KiCad), Prototyping (Code)*, and *Testing*.
- ⚡ **Real-Time Collaboration:** See updates instantly across your team with WebSocket-powered live synchronization. 
- 🗂️ **File Versioning:** Keep track of schematics, gerber files, and 3D models with robust file version control.
- 🔒 **Role-Based Access:** Secure, permission-driven access ensuring only authorized personnel can view or edit sensitive IP.
- 📅 **Integrated Calendar:** Keep track of manufacturing deadlines, component lead times, and team meetings in one place.
- 📝 **Engineering Notes:** Built-in rich text documentation for logging test results, BOM changes, and design decisions.
- 📊 **Dynamic Dashboards:** At-a-glance metrics showing active projects, upcoming deadlines, and team productivity trends.

## 🚀 Tech Stack

- **Frontend:** React, Tailwind CSS, Vite
- **Backend:** Node.js, Express
- **Database:** PostgreSQL (Supabase)
- **Real-Time:** Socket.io
- **Authentication:** JWT, Supabase Auth
